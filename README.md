# 🗓️ Turnos Justos

> Fair shift-rota generator: balances shifts per person, respects days off and never puts someone on a morning shift right after a night shift.

**Free · open source · 100% in your browser (nothing is uploaded).**

<sub>[🇪🇸 Español abajo](#-español)</sub>

## Features
- Weekly printable rota
- fairness report
- uncovered-shift warning

## Use
Open `index.html` — no install, no server, no build. Host it free on GitHub Pages.

## Basis
Algoritmo voraz de reparto equilibrado.

## ⚠️ Disclaimer
Orientative tool — not legal, tax or financial advice. Check your specific case with a professional.
